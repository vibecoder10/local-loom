# Reusable element library

Use RUBRIC elements as the central index for every reusable video asset. Register every newly generated graphic, image, Broll clip, SVG, 3D object, background, sound and reusable composition with source paths, provenance and tags before calling production complete. Keep one master asset and deduplicate copies by content hash. Source files remain organized in their video or common folders. Preview an existing element before building a substitute. The catalog stores templates, layouts and patterns first. Media belongs only as the example inside a pattern: the painted sunset layers demonstrate the four-layer parallax, they are not the asset. Categories: Layouts, Motion, Infographics, Hero text, 3D objects, Graphics, Icons (agent icons and brand marks), Backgrounds, Broll, Sound effects and Music (the owner's theme and generated scores, private). Actual site captures stay in their footage folders, not in the catalog. Design studies stay outside the library. Graphics and Broll show at their natural aspect in a bento column layout, never cropped. An empty category means no finished asset exists, not permission to label a placeholder as completed media.

The library lives in the package's `library/` folder: open `library/index.html`; `node library/register-asset.mjs entry.json` validates and adds an entry to `library/assets.json`, then rebuilds the page; `node library/build.mjs` rebuilds on its own. Paths in entries are relative to the package root (for example `assets/components/my-element/poster.png`). Keep new element folders inside `assets/` so the package stays portable.

Choose 16:9 landscape or 9:16 portrait with the compact canvas control. Hover or keyboard-focus a card to preview it; stop and dispose its player when leaving. Only one preview runs at a time. Real 3D renders on the selected canvas with the correct camera aspect, never a stretched portrait raster. Use a 0.5-second Y-axis entrance turn, a 0.1-second fade and no entry blur. Each 3D appearance in a video lasts at most 3 seconds including transitions; continue a longer idea with a simple infographic or hero text within the 6-second scene ceiling. Preserve source aspect and recompose text and diagrams. Hover/focus is an explicit preview request, not page-load autoplay. Return links without opening tabs automatically.

## Image burst and Icon Title

An image burst uses at most three fresh concepts from your agent's native image-generation tool (ChatGPT's when your agent runs on a GPT model), never a paid video provider in quick succession, each with a synchronized audible click. Preserve image IDs and prompts. Never repeat those images later in the same video or present a generated concept as an actual resource capture. Generated images enter from fully offscreen with a 0.4-second eased movement and motion blur, settling sharp. Landscape openings have no hook text.

Icon Title is a full-screen hero composition with one dominant tool-specific icon and a large centred Copernicus Bold tool name, revealed in stages. Ordinary titles have no small decorative adjacent icon. For infographics, an AI tool uses its faithful logo SVG from Icons and agents use the ROBO agent icon. Keep authentic marks intact; prefer balanced symmetry for new pixel symbols only when their meaning allows it. The library's brand assets are identity references, not interchangeable generic symbols. Real 3D app components use editable beveled app-window geometry and a timeline-driven interface texture with the app's authentic mark and a typed prompt. Preserve app identity, large readable input, source and GLB. They are illustrative app components, never claimed as captured product evidence. Typing follows the entrance and settles for reading within the 3-second appearance. Preview both aspect ratios without stretching.

Eight working patterns are available: many-to-one collection, hub-and-spoke system, orbital ecosystem, tool category strip, numbered-input convergence, a 2D globe/agent network, Icon Title and an image burst. Each includes editable configuration, source JavaScript and both aspect ratios. The burst ships with three explicit placeholders and click cues, not generated artwork. The globe is an SVG diagram, not freely rotating 3D. Treat these structures as examples, not the only allowed diagrams; use only script-supported numbers and avoid tiny labels or unsupported metrics.

Keep the gallery minimal: simple search, category navigation, asset names, one Add button per card, and a dark/light toggle (dark default, stored as `robo-theme`). The grid is fluid: as many columns as fit the width, never more than six, so zooming out shows more cards. The fourteen Motion cards play the Motion Studio recipes with GSAP on hover (same 0.4-second timing, sharp ease, moving blur), and Add copies the matching GSAP recipe into the agent prompt. Add collects the element in a small bottom-right tray and copies an agent-ready selection, including source paths, pattern configuration and selected aspect. Include Copy in the tray and an honest selectable-text fallback when clipboard access is blocked. Persist the selection, allow item removal, and omit status filters, font loaders, verbose rules, descriptions and extra card buttons. Editable pattern JSON remains in the source files. For rendering, drive the returned player's renderAt method from scene-local timeline time; do not run the interactive play loop during export. Preserve the pattern source and configuration with the video. Previews remain still until hover or keyboard focus. Custom components register with `element` (the global name), `elementPath` (the script) and `config`; the library mounts them through the contract in creating-elements.md and drives `renderAt` from hover time.

## Hero text

Every narrated number or quantity uses oversized, centred Copernicus Bold hero text with the number in ROBO orange and its label readable. Values below 100 show the final number immediately, with no count-up: "4 Free Plugins" displays 4 throughout. Values of 100 or more count over 0.5 seconds, then hold the script-supported value: "275,000 characters" counts 274,611 to 275,000. This overrides the standard 0.4-second transition. Cover repeated numeric mentions with distinct hero compositions without replaying an entire image or infographic sequence. Preserve approximations: "thousands" becomes "1,000s" or "Thousands", never an invented exact total; if no exact value exists, animate the honest quantity treatment rather than fabricate a numeric endpoint. A name such as 21st.dev does not mean 21 items. Both number and label use Copernicus; body copy remains Outfit.

Compute exact counts from scene-local time with clamped ease-in-out progress and rounding at the script's precision. Never use random values or accumulating timers. Backward seeks reproduce the same value. At 15 fps the first exported frame at or after 0.5 seconds shows the exact endpoint. Hold it, and fit the complete number and label in either aspect ratio without text shifts. Browser labels use the actual hostname plus at most one path segment, never protocol, query, fragment or trailing slash; retain full source URLs separately. Infographics show meaningful relationships, never a scanning line over a fake-code monitor.

## Editable concepts and portability

Image-to-editable infographics are an optional workflow, not a requirement to convert every generated image. Generate and inspect a concept first, retain its prompt and source, then reconstruct meaningful parts as separate HTML/SVG elements. Preserve the useful composition while making relationships, text and geometry editable; do not place the complete raster inside a frame and call it reconstructed. Stage each part in narrative order with the established eased entrances. During the visible hold, continue a subtle pan or slow rotation from scene-local time instead of freezing after entry. Expose hold-motion amplitude and depth/tilt controls, including zero motion for accessibility or a still export; keep motion restrained enough for reading. Verify at least two settled timestamps differ when motion is enabled and reproduce exactly after backward seeks.

The Huly examples use editable task, calendar, discussion, workspace and completion elements with CSS perspective. Preserve each concept's independent source parts and camera configuration. Use its supplied create/renderAt/setConfig/resize/dispose API, with hold motion and depth configuration included in the clipboard selection. Recompose both aspect ratios and check that all essential nodes remain visible. This is layered HTML/SVG depth, not mesh geometry or a GLB. Edit source parts and rebuild embedded SVG copies with the included sync helper. Retain the native concept as provenance and a separate Graphics entry; distinguish a generated reference from a raster actually shown in the final video.

For parallax, preserve independent foreground, subject and background layers, their source images and a deterministic camera path. Expose depth or movement amplitude without inventing hidden scene content. Recompose the layer positions and crop for each aspect ratio instead of stretching the finished video. Keep the layer source and native-generation provenance with the reusable component; preview and render from the same scene-local clock.

Keep the extracted package together: library, assets and skills. The package library is library/index.html; assets contains portable GLBs, local preview engines, SVGs, transparent artwork, the counter helper and the eight-reel template. Copying only the skill folder installs its instructions but does not install the browsable asset library. Copernicus font software is not redistributed. Use an installed licensed copy when available, otherwise the documented serif fallback; do not show a font upload control in the gallery. Outfit and included engine dependencies retain their notices. Private music, voice tracks and source captures stay in the private project catalog. Replace the community browser placeholder with an actual capture before presenting it as evidence.
